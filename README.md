# 星耀中国 · 万里同月 — 互动网页

万里安中秋国庆活动「星耀中国」互动网页：员工上传含月亮/国旗的照片 → 点亮所在地区星图 → 写一句话 → 答对灯谜得星光点；总部在后台下载照片与留言，制作明信片寄往各货站。

## 运行（本机 / 内网）
```bash
# 使用托管 Node（或任意 Node 18+）
node server.js
# 或指定端口： PORT=8080 node server.js
```
启动后访问：
- 互动页（员工用）： http://localhost:3000
- 管理后台（总部用）： http://localhost:3000/admin
- 活动题库（总部查看）： http://localhost:3000/questions.html

## 联网部署（让全员在外网访问）
本项目是 **Node 后端 + 静态前端**，需要能跑 Node 的主机（注意：CloudStudio 等纯静态托管**不支持** Node 后端，无法直接使用）。

**任选一种：**
1. **自有服务器 / VPS**：把整个 `wanlan-festival/` 目录上传，安装 Node 18+，执行 `npm start`（即 `node server.js`）。建议用 `pm2` 守护进程 + `nginx` 反代并配置 HTTPS 域名。数据存于服务器本地的 `data/data.json` 与 `uploads/`。
2. **Node PaaS（最省事，推荐 Render / Railway / Fly.io）**：
   - 新建一个 Web Service，关联代码仓库（或手动上传目录）；
   - 启动命令填 `npm start`；
   - 平台会自动注入 `PORT` 环境变量（代码已支持）；
   - 免费档通常带临时磁盘，活动期间数据足够；如需长期留存可挂载 Volume。
3. **内网穿透**：本机跑 `node server.js`，再用 frp / ngrok / 企业 VPN 把 3000 端口暴露给外网（适合临时活动）。

> 部署后，把互动页地址（如 `https://你的域名/`）发给各货站员工即可。

## 后台口令（公网部署必开）
一旦暴露到公网，任何人都能进 `/admin` 下载全员照片与留言，因此上线前请设置口令：
```bash
ADMIN_TOKEN=你的强口令 node server.js
```
设置后：
- 访问后台需带 `?token=你的强口令`（如 `https://你的域名/admin?token=你的强口令`）；
- 下载图片/CSV 也需同样口令；
- **不设置则保持开放**（仅限内网/本机使用）。

## 活动操作流程
1. **征集（9月初–9/10）**：各站员工在互动页上传照片、选地区、写留言（留言保持神秘，不做提示）。
2. **点亮星图**：上传后该地区节点在真实中国地图上亮起，下方滚动显示「昵称 点亮了 地区 的星图」；目标点亮约 50 人。
3. **灯谜得星光点**：上传后出现随机灯谜/小问答（共 50 题，中秋/国庆/航空/公司类），答对后登记姓名，活动结束统一在企微小程序「星耀万里」发放星光点。
4. **总部制作（9/15–20）**：管理员后台「打包下载全部图片」+「导出 CSV」，由总部人员把照片印成明信片、誊抄留言（或老板寄语），寿星按公司生日记录另加生日祝福。
5. **寄送（9/20–24，海岛前置）**：明信片寄往各货站；岱山提前发货。
6. **线下同庆（9/25）**：各站拆箱读卡、云端团圆夜、Q3 生日会、买点吃的。

## 数据存储
- `data/data.json`：所有上传记录（昵称/地区/留言/星光点姓名）
- `uploads/`：上传的原始图片（文件名即记录 id）
- 数据均在部署所在服务器本地，不外传任何第三方。

## 备注
- 纯前端 + Node 内置模块，零第三方依赖。
- 题库共 50 题，总部可在 `/questions.html` 查看全部（含正确答案）。
